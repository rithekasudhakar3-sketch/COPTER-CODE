========================================================================
🚀 THE 6-STEP GITHUB CHEAT SHEET FOR THE TEAM 🚀
========================================================================

1. CREATE AN ISSUE (GITHUB)
   Find an issue or feature to work on. Let the team know what you're fixing.

2. CREATE  BRANCH (GITHUB)
   The branch can be created ,with automatic feature once you create an issue

3. COMMIT
   git add .
   git commit -m "feat: short description of what you built"

4. PUSH
   Send your local branch up to GitHub for the first time:
   ------------------------------------------------------------------
   git push -u origin feature/yourname-taskname
   ------------------------------------------------------------------

5. ASK FOR A REVIEW (PULL REQUEST)
   • Go to GitHub.com.
   • Click the green [ Compare & pull request ] button on the yellow banner.
   • Add a quick note about what you did.
   • On the right side, assign a teammate as a "Reviewer".
   • Click the green [ Create pull request ] button.

6. REVISE, APPROVE & MERGE
   • Teammate looks at your code, leaves feedback, and clicks "Approve".
   • Once approved, the green [ Merge pull request ] button unlocks!
   • Click Merge, confirm it, and click [ Delete branch ].
